Land Bangla Orchid HTML Demo থেকে APK তৈরির নির্দেশনা

১) এই ZIP ফোনে Extract করুন।
২) Extract করা ফোল্ডারের ভেতরের সব ফাইল/ফোল্ডার আপনার GitHub Repository-র root-এ Upload করুন; বাইরের ফোল্ডারটি নয়।
৩) `.github/workflows/android-apk.yml` ফাইলটি নতুনটির দিয়ে Replace/Overwrite করুন।
৪) Commit changes চাপুন।
৫) GitHub → Actions → `Build Land Bangla Orchid APK` খুলুন।
৬) সবুজ টিক হলে রান খুলে Artifacts → `land-bangla-orchid-apk` ডাউনলোড করুন।
৭) ডাউনলোড ZIP My Files-এ Extract করে `app-debug.apk` ইনস্টল করুন।

গুরুত্বপূর্ণ: এটি আপনার Interactive HTML ডেমোকে Android WebView অ্যাপ হিসেবে চালায়। ডেটা ফোনেই স্থানীয়ভাবে থাকে; একাধিক মালিকের মধ্যে অনলাইন শেয়ারিং, প্রকৃত লগইন, স্বয়ংক্রিয় SMS বা ইমেইল চালু হয় না।
